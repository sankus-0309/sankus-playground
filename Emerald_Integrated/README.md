# エメラルド統合版

日本版『ポケットモンスター エメラルド』をベースに、ホウエン・ジョウト・カントーの3地方をひとつの冒険として遊べるようにした非公式の改造パッチです。

## 制作の目的

エメラルドの雰囲気や第3世代の遊び心地を残しながら、殿堂入り後も新しい街を巡り、ポケモンを育てた手持ちでさらに強い相手に挑める作品を目指しました。登場するポケモンは第1〜第3世代です。

## 主な特徴

- **3地方をひとつのセーブで冒険**：ホウエンから始まり、殿堂入り後にジョウト、続いてカントーへ進みます。各地方のジムや四天王に挑戦でき、クリア後はレッドやダイゴとも戦えます。
- **映画に登場する街やエリアを追加**：アルトマーレ、ラルースシティ、ファウンスを探索できます。ラルースシティの動く床や、アルトマーレの「ひみつの庭」など、街ごとの仕掛けやBGMも作り込んでいます。
- **地方をまたいで「そらをとぶ」**：3地方のマップを切り替え、訪問済みの街を選んで移動できます。
- **ラルースシティ独自のバトルタワー**：ダブルバトル専用で、レベル50とオープンレベルの2部門があります。プレイヤーは参加制限のある伝説のポケモンを2体まで編成でき、獲得したBPは景品や個体値アップに使えます。
- **育成と収集の変更**：一部の通信交換進化は通信なしで進化できます。追加された伝説のポケモンのイベントでは、倒してしまっても捕まえるまでは再挑戦できます。

## 既知の不具合

- ホウエンの111・113番道路では、移動時に一部引っ掛かることがあります。
- ポケモンセンターのミニマップの表示がバグってます(そらをとぶは問題ありません)
